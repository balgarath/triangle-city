# Triangle City

An 80s night city drawn from nothing but triangles, looping forever. It runs in a
browser, on a Roku, and on an Android TV box via the installer below.

Watch it in a browser: <https://geovisual.net/triangle-city/>

## Downloads

The Android installer is published under [Releases](../../releases). The newest
build is always at:

```
https://github.com/balgarath/triangle-city/releases/latest/download/triangle-city-latest.apk
```

That URL follows the latest release, so a link you have already shared keeps
working after a new build.

### Installing

This is a sideloaded app, not a Play Store listing, so Android asks permission
before installing it. Download the APK, open it, and allow installs from your
browser when prompted.

## What it is

Every building, sign and figure is a triangle. The city scrolls on a 270 second
loop and the neon advertises businesses that do not exist. Two real Geovisual
Creations installations, the Obelisk and a geodesic dome, stand in the skyline
as landmarks.

Built by [Geovisual Creations](https://geovisual.net).
